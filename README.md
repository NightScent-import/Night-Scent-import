# Night Scent Import — Catálogo de perfumes

Catálogo web de perfumes árabes, de diseñador y nicho (Ensenada, Buenos Aires).
Los clientes eligen perfumes o decants y consultan precio y stock por WhatsApp.

## Contenido

- `index.html`: la página completa en un solo archivo (estilos, código e imágenes incluidos).
- `.nojekyll`: evita que GitHub Pages procese el sitio con Jekyll.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `night-scent-import`).
2. Subí el contenido de esta carpeta (`index.html`, `.nojekyll` y `README.md`) a la rama `main`.
3. En el repositorio, entrá a **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guardá. En un par de minutos la página queda en `https://TU-USUARIO.github.io/night-scent-import/`.

## Actualizar el catálogo

Reemplazá `index.html` por la versión nueva y hacé commit. GitHub Pages se actualiza solo.
